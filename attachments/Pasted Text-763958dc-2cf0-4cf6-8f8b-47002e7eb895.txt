Apply Theme

- Validate that the user is authorized to change the wedding's theme.
- Apply the selected theme to that specific wedding.
- Update all relevant wedding screens and components.
- Persist the applied theme using the existing data model.
- Update the currently visible screen without requiring a manual refresh.
- Show a clear confirmation message after the save and application succeed.

- Discard the unconfirmed selection.

- Explain that the change failed.
