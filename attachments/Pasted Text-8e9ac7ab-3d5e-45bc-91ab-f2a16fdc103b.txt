Upgrade my existing application's private Developer Login into a full-fledged Developer Command Center / AI Engineering Console.

This is for the application's owner/developer only. It must work with the EXISTING application, existing source code, database, authentication, GitHub repository, and deployment setup. Do not create a fake/simulated developer environment.

CORE PURPOSE

I want to be able to maintain and improve my entire application from this Developer Command Center without manually opening the source code whenever possible.

It should function like a private AI software engineer + admin console for this application.
