2. Make swipe navigation extremely fast and responsive

The app has five main sections: Home, Feed, Live, Album and More.

The current swipe functionality is not responsive enough. I want quick, natural finger flicks to trigger navigation almost immediately.

Swipe detection

- Detect swipes across the entire usable screen, including ordinary content areas and empty spaces, rather than only a small designated area.
- Recognize short, fast finger flicks using both movement distance and gesture velocity.
- Do not require a long drag or a large movement before recognizing a swipe.
- Start processing touch input immediately, without unnecessary timeouts or confirmation delays.
- Tune thresholds for real mobile touchscreen use.
- Make swiping feel natural, effortless and consistent.
- Trigger exactly one section change for each completed swipe.
- Prevent duplicate events, accidental double navigation and conflicting gesture handlers.

Directional behavior

- Swipe left: immediately navigate to the next section.
- Swipe right: immediately navigate to the previous section.
- Do not loop from More to Home or from Home to More.
- At the first or last section, ignore swipes that would move beyond the available sections.
- Update the active bottom-navigation indicator and displayed section together.
- Use a very short, lightweight transition or no transition if animation causes noticeable delay.
- Make navigation independent of slow network requests.

Gesture compatibility

- Support swipes throughout non-interactive screen areas.
- Do not accidentally trigger navigation when the user is typing, selecting text, interacting with a dropdown, tapping buttons, controlling the camera, playing a video, dragging an element or using album/gallery gestures.
- Preserve smooth vertical scrolling. A vertical scroll must not trigger horizontal section navigation.
- Handle diagonal gestures intelligently by identifying the dominant direction.
- Inspect event propagation, pointer and touch handlers, nested containers and existing gesture libraries.
- Remove duplicate listeners and resolve conflicting handlers.
- Where content consumes touch events, implement compatible gesture handling where technically safe.

Preserve app state

When navigating between sections, preserve drafts, scroll positions, selected options and relevant UI state.

Never interrupt an active livestream or camera session because of a swipe. Do not break Feed replies, album browsing, privacy controls or other existing interactions.

Swipe acceptance test

A single quick finger flick should reliably navigate exactly one section in the intended direction, with an immediate response and no noticeable lag. Test short, fast flicks, longer swipes, diagonal movements, rapid consecutive swipes and gestures from different screen areas.
