PART 7 — Add Swipe Navigation Between the Five Main Sections

1. Home
2. Feed
3. Live
4. Album
5. More

- Swipe left to navigate to the next section.
- Swipe right to navigate to the previous section.
- Follow this exact order: Home → Feed → Live → Album → More.
- Do not loop from More back to Home or from Home back to More.
- At the first and last sections, ignore swipes that would go beyond the available sections.
- Use smooth, natural horizontal transitions.
- Avoid excessive animations or noticeable delays.

Keep bottom navigation synchronized

- When a swipe changes sections, automatically highlight the correct bottom navigation icon and label.
- When a user taps a bottom navigation item, navigate normally to that section.
- Tapping and swiping must use the same existing navigation state and routing system.
- Do not create duplicate pages or separate navigation stacks for the same sections.

Preserve section state

When moving between sections, preserve state wherever practical, including:

- Unsent Feed post drafts.
- Unsent comment and reply drafts.
- Feed scroll position.
- Selected album content.
- Selected wedding function and audience settings.
- Active livestream sessions and their camera or audio state.

Navigation must not reload the entire application, restart a livestream, submit a draft, or reset user data.
