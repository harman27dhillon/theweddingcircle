TASK: MAKE IPHONE-STYLE ANIMATIONS AND GLASSMORPHISM THE PERMANENT DEFAULT UI SYSTEM FOR THE WEDDING CIRCLE.

I want The Wedding Circle to retain a premium, modern iPhone-inspired user experience, including smooth transitions, translucent glass panels, background blur, and fluid navigation.

IMPORTANT DISTINCTION:
The eight wedding themes control the wedding's visual identity, colors, typography, floral decorations, and ornamental styling.

The iPhone-style animations, glassmorphism, interface behavior, and navigation transitions must remain the DEFAULT DESIGN SYSTEM across all eight themes.

Changing a wedding theme must NOT remove, disable, or replace these effects.

1. GLASSMORPHISM AS THE DEFAULT

Apply a consistent glass-style design to suitable interface elements throughout the app:

- Top header and account controls
- Bottom navigation bar
- Floating buttons and action controls
- Chat composer and attachment menus
- Chat message panels where appropriate
- Modal windows and dialogs
- Bottom sheets, dropdowns, and contextual menus
- Live-stream controls and floating player controls
- Album controls and media overlays
- Host Control panels and settings windows
- Loading indicators and transient notifications

Use:
- Translucent backgrounds
- Background blur using backdrop-filter where supported
- Subtle translucent borders
- Soft, restrained shadows
- Layered depth and gentle highlights
- Carefully controlled transparency
- Readable text and icons with sufficient contrast

Do not make every component transparent. Important content cards, wedding artwork, text, and media should remain clear and legible.

Apply glass effects where they improve the interface, not indiscriminately.

2. IPHONE-INSPIRED ANIMATIONS

Make the app feel fluid and responsive, inspired by iOS interface transitions without attempting to reproduce Apple's proprietary interface exactly.

Implement smooth, consistent animations for:

- Opening the app and entering a wedding
- Landing-page transitions
- Switching between Home, Chat, Live, Album, and More
- Opening and closing modal windows
- Opening dropdowns and bottom sheets
- Expanding and minimizing the Live player
- Selecting wedding cards and shortcut buttons
- Pressing buttons and selecting navigation items
- Opening media previews and returning to the previous screen

Use appropriate combinations of:
- Fade transitions
- Smooth sliding transitions
- Subtle scale transitions
- Spring-like easing for selected interactions
- Gentle opacity changes
- Short, responsive micro-interactions

Transitions should feel continuous and natural, not slow or excessively animated.

Suggested timing:
- Button feedback: 120–200 ms
- Small menus and dialogs: 180–280 ms
- Main navigation transitions: 220–350 ms
- Larger page transitions: 250–400 ms

Adjust timing when necessary to keep the interface responsive.

3. PRESERVE THE EXISTING SWIPE AND NAVIGATION BEHAVIOR

Keep all existing navigation functionality.

- Preserve the current bottom navigation actions.
- Preserve any existing swipe gestures between sections.
- Avoid gesture conflicts with scrolling, the camera, media viewers, and live streams.
- Do not introduce extra navigation layers or unnecessary loading screens.
- Ensure transitions work on Android browsers, installed PWAs, and supported mobile devices.

Use smooth transform and opacity animations where appropriate instead of unnecessarily re-rendering entire pages.

Theme changes must not reset animation settings or remove glass effects.

Reuse these shared styles across existing components rather than implementing unrelated animations and glass effects separately on every page.

Keep the existing eight-theme configuration compatible with this system.

- Maintain accessible contrast and visible focus states.
- Respect the user's reduced-motion preference.
- Prevent animations from blocking buttons or delaying user actions.
- Avoid layout shifts and preserve scrolling behavior.
