1. CORRECT MESSAGE ALIGNMENT

Every participant viewing the same chat must see:

- Messages sent by OTHER participants aligned to the LEFT.
- Messages sent by the CURRENT logged-in user aligned to the RIGHT.
- The alignment must be calculated relative to the identity of the person currently viewing the chat.

For example:
If Alice sends a message, Alice sees it on the right.
Bob sees Alice's same message on the left.
If Bob replies, Bob sees his reply on the right, while Alice sees that reply on the left.

Never determine alignment using a fixed sender name, display name, host role, or developer role.

Use the authenticated user's stable ID and the message sender's stable user ID to determine whether a message belongs to the current user.

Do not compare display names because different users can have identical names.

If the existing message data does not expose the correct sender ID, inspect and repair the existing data flow without replacing real messages with mock data.

- Keep consistent spacing between messages.
