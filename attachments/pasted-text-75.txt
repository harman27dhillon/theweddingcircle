5. Cache-Control headers for HTML, JS, CSS and static assets.
6. IndexedDB, localStorage and sessionStorage conflicts.
7. Whether different application versions can run simultaneously.
8. Whether an old service worker continues serving outdated files after deployment.

Determine whether a mixed-version application or stale cached assets could explain the problem.

- Identify the actual root cause using code and production evidence.
