1. Make the chat message bar and bubbles more premium

Upgrade the existing message presentation so it feels polished, elegant, and purpose-built for weddings.

- Use refined rounded message bubbles with consistent spacing, balanced proportions, and clean alignment.
- Create a smooth, naturally curved bubble tail that slopes toward the sender's avatar rather than using a sharp triangular point.
- Keep avatars the same height as their bubbles or slightly smaller.
- Use subtle depth, delicate borders, and restrained shadows instead of thick outlines or excessive white containers.
- Incoming messages should use a soft ivory or cream surface with readable dark text.
- Verified bride/groom messages should use an elegant golden fill with strong text contrast, including a matching curved tail.
- Keep the existing peach floral wedding background, but ensure messages remain easy to read against decorative flowers.
- Make text, voice notes, photos, and videos feel like part of the same visual design system.
- Keep spacing consistent between messages, avatars, and media.

Use the attached image as visual inspiration, but implement a more refined, production-ready version rather than copying its exaggerated sizes or every decorative detail.
