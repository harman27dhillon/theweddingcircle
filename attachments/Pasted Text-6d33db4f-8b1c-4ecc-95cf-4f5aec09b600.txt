Website: https://theweddingcircle.grok.me/

1. FIX THE GUEST INVITATION FLOW — HIGHEST PRIORITY

Current problem:
A guest opening an invitation can get:
“This invitation is not on this device.”

This is wrong for a wedding invitation.

A wedding invitation link must work when:

- forwarded on WhatsApp
- opened on another phone
- opened in Chrome/Safari
- opened from Instagram/SMS/email
- opened from a QR code
- opened by someone who has never visited the site before

Remove any device-specific/local-storage requirement for validating a legitimate invitation.

Use the invitation ID/slug from the URL as the source of truth.

Flow should be:

Shared invitation link
→ Wedding invitation landing page
→ Guest enters name (optional if already known)
→ Enter wedding
→ Wedding experience

Do NOT force guest signup/login.

If an invitation is genuinely invalid or expired, show a proper recovery screen with:

- “This invitation link is invalid or expired.”
- “Ask the couple for a new invitation link.”
- “View sample wedding”

2. FIX “WATCH AS A GUEST”

→ Family/community area
→ Photos/memories
→ Schedule/events
→ Back to wedding home

Every button must actually work.
